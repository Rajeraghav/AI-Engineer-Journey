
# Day 08 - CNN MNIST Digit Classification

## Project

Implemented a Convolutional Neural Network (CNN) for handwritten digit classification.

## Dataset

- Dataset: MNIST handwritten digits
- Samples: 1797
- Features: 64
- Image size: 8 × 8
- Classes: 10
- Classes: 0–9

## Algorithm

Convolutional Neural Network (CNN)
